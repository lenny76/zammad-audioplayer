Trascrizione Whisper · facoltativa

Configura OpenAI oppure un server Whisper con API compatibile. Premendo Trascrivi, l’allegato viene inviato all’endpoint salvato.

La chiave viene salvata solo in questo profilo del browser, senza sincronizzazione, e non è accessibile ai content script. L’archivio locale non è un vault cifrato. Puoi utilizzare un proxy aziendale per conservare la chiave sul server.
